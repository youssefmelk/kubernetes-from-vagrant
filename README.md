# Kubernetes from Vagrant

Vanilla Kubernetes from Vagrant and VirtualBox

## Description
This is an educational project that I am creating to teach myself Kubernetes.

Using a Vagrantfile and Oracle VirtualBox, 3 Ubuntu Server Virtual Machines will be made: 1 control node, and 2 worker nodes. These 3 nodes will be used as a Kubernetes Cluster to perform all kinds of tests and experiments.
